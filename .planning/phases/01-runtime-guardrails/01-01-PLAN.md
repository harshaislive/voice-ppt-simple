## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser or script caller -> `/api/cms/*` | Untrusted external callers must not reach operational CMS mutations or preview TTS without admin auth |
| browser or script caller -> `/api/analytics/*` | Untrusted callers must not forge session analytics or internal operational events |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | S | `server/routes/cms.js` | mitigate | Add `requireAdminApiKey` to all mutating CMS and preview routes per D-01 |
| T-01-02 | T | `server/routes/analytics.js` | mitigate | Require `requireSessionControl({ keys: ['sessionId'] })` for session-scoped analytics and separate any admin/internal path per D-02 |
| T-01-03 | R | CMS and analytics route surface | mitigate | Add Jest + Supertest negative-path tests so rejected access attempts are preserved by regression coverage |
| T-01-04 | I | read-only CMS routes | accept | Preserve only the specific read routes needed by the client surface per D-03; no mutation or preview data remains public |
</threat_model>
